Flying Speaker Notes

Deine Notizen schweben mit transparentem Hintergrund über deinem Gesprächsfenster. Eine kostenlose Mac-App für Freunde.

Für Apple Silicon herunterladen

Ab macOS 14 · M1 oder neuer · Kostenlos · Manuelle Updates

Einmal installieren

  1. Die heruntergeladene DMG öffnen und Flying Speaker Notes in Applications ziehen.
  2. Die App im Programme-Ordner öffnen. macOS kann sie zunächst blockieren, weil diese kostenlose Version nicht von Apple notarisiert ist. Die Meldung schließen.
  3. Systemeinstellungen → Datenschutz & Sicherheit öffnen. Bei Flying Speaker Notes auf Dennoch öffnen klicken und den Start dieser App bestätigen.

Anleitung von Apple. Ein vom Arbeitgeber verwalteter Mac kann diese Freigabe verhindern.

Mit einer Notiz starten

Eine Notiz anlegen, Text einfügen oder eine lokale PDF importieren. „Im Overlay anzeigen“ blendet die Notiz als schwebendes Fenster ein. ⌘F18 schaltet das Overlay um; das Kürzel lässt sich in den Einstellungen ändern. Beim Teilen des ganzen Bildschirms kann das Overlay sichtbar sein.

Google Docs verbinden, wenn du möchtest

„Aus Google Docs importieren“ → „Verbinden …“ wählen und mit dem eigenen Google-Konto anmelden. Den Lesezugriff erlauben, einen Dokument-Link einfügen und „Importieren“ wählen.

Diese App wird in einem kleinen Freundeskreis geteilt und ist bei Google nicht verifiziert. Google kann bei der Anmeldung eine entsprechende Warnung anzeigen. Deine Organisation kann den Zugriff sperren.

Manuelle Updates

Flying Speaker Notes über das Menü beenden und mit dem aktuellen Download ersetzen. Das Schließen des Editorfensters allein beendet die Menüleisten-App nicht. Deine Notizen liegen getrennt von der App und bleiben erhalten.

Deine Daten

Notizen und importierte Bilder werden auf deinem Mac gespeichert. Verknüpfte Google Docs werden direkt bei Google auf Änderungen geprüft. Bearbeiten speichert lokal; das Zurückschreiben in Google Docs braucht eine gesonderte Aktion und Zustimmung. Google-Zugangsdaten bleiben im macOS-Schlüsselbund. Die App hat keine Nutzungsanalyse und keinen Server des Entwicklers; sie sendet deine Notizen oder Google-Zugangsdaten nicht an Max. Externe Bilder werden direkt von ihrer Quelle geladen.
